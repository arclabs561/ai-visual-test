@chjara I think fedi currently has very little protection from programmatic, "4chan-style" trolling attempts. Mass creating a billion instance identities, spamming everyone's notifications with shock images, that kind of stuff (I'm surprised that it hasn't happened yet...). The only solution right now is "manual block by admins on sight" and it isn't going to work against any dedicated spammers. There are possible solutions like reputation & greylisting but I don't think anyone's working on that.

If the trolling ever arrives, this is the situation I'm most afraid of: without better tools, everyone would stop federating with unknown instances, and only allowing instances in the trusted list. Initially it would be a temporarily workaround against trolling, but it's likely going to be stay as a semi-permanent policy.
