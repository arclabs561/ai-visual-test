Overview

The Things Indoor Gateway (TTIG) is designed to be a fully compliant, low-cost LoRaWAN gateway, with WiFi as the backhaul. The gateway comes with a wall plug, or can be powered over USB-C on 900mA, making the gateway even suitable for applications that require dynamic coverage.

TTIG is an 8 channel LoRaWAN indoor gateway and one of the first gateways to support the state-of-the-art BasicStation Protocol. The simple setup takes less than 5 minutes. The setup and connectivity is over WiFi. It can be powered via a USB-C cable or via the power outlet and has a built-in omnidirectional antenna.

More information is available in the datasheet and on the website of The Things Network. See also the Wiki FAQ.
