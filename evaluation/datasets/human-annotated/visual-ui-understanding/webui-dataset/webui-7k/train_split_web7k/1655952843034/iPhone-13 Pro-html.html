Miniva – Free WordPress Theme

A fast, lightweight, and mobile-friendly WordPress theme for bloggers. Miniva is built with simplicity, accessibility and performance in mind. The clean and minimal design helps readers focus on your content.

It supports most of WordPress theme standard features like custom background, custom header, custom logo, custom menu, featured images, footer widgets, full-width template, left/right sidebar, threaded comments, RTL and translation.

Optimized for Speed

Miniva is optimized to load quickly by using as little resources as possible.

  • No CSS framework
    Miniva doesn’t use bootstrap, foundation, or any other big CSS framework. Only a single CSS file is loaded by default.
  • No web fonts
    Miniva doesn’t use Google font, typekit, or any other web fonts. It uses only system font, so the browser doesn’t have to download any font files.
  • No icon fonts
    Miniva uses only a small number of icons via inline SVG.
  • No jQuery
    All scripts in the theme are written in vanilla JS and work without jQuery. Your site will only load jQuery when you activate a plugin that requires it.

Plugins Compatibility

Miniva is built with only a small number of features to keep it simple and not bloated with hundreds of options. If you need more functionality, Miniva is designed to work with Jetpack and other popular plugins.

  • Jetpack
    Jetpack enables you to connect your blog to a WordPress.com account to use the powerful features normally only available to WordPress.com users. Miniva supports these Jetpack modules and provides extra styling:
    – Featured content
    – Infinite scroll
    – Content options
    – Social menu
  • Breadcrumb NavXT
    Breadcrumb NavXT is a plugin that adds a breadcrumb navigation showing the visitor’s path to their current location. Miniva displays the breadcrumb navigation above the content area when this plugin is active, and provides some styling.
  • WP-PostViews
    WP-PostViews is a plugin to display how many times a post/page had been viewed. Miniva displays the number of views below the posts/pages when this plugin is active, and provides styling for the Views widget.
  • Contact Form 7
    Contact Form 7 is a simple but flexible contact form plugin. Miniva provides styling for the default contact form.
  • Mailchimp for WordPress
    Mailchimp for WP adds various highly effective sign-up methods to your site. Miniva provides styling for the default sign-up form used in widgets and pages.
  • Flex Posts
    Flex Posts is a widget to display posts with thumbnails in various layouts. By using Flex Posts in the Widgetized page template in Miniva, you can display a list of posts from several different categories.
