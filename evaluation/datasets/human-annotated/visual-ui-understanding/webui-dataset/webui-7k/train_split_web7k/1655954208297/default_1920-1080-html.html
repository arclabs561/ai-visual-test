SuRF Information

The Succinct Range Filter (SuRF) is a fast and compact data structure for approximate membership tests. It answers:

  • Does a query key likely exist in the input keys?
  • Does a query key range likely have any matching key in the input keys?

SuRF may return a false positive ("True" for no match). Using (especially long) suffixes may reduce false positives.

This demo uses the SuRF C++ implementation compiled into Javascript.

Please see our SIGMOD paper for more information.
