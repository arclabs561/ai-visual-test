IceWM is a window manager for the X Window System (freedesktop, XFree86). The goal of IceWM is speed, simplicity, and not getting in the user's way.

News

  • Slackware packages at http://linuce.free.fr/packages/icewm/ by LiNuCe
  • Updated themes section, FAQ updated (2004-06-15)
  • Updated Theme Creation Howto (2003-10-27)

Other downloads

  • Slackware packages are available also on linuxpackages.net
  • RPM packages you can find on ATrpms and DAG

Features

  • Fully usable with keyboard
  • Alt+Tab window switching
  • Efficient resource usage
  • Task bar (optional)
  • Multiple workspaces
  • Themes
  • Usable with GNOME and KDE environments
