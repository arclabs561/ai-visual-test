FlowForge Inc

FlowForge is creating a low-code programming platform based on the OpenJS Foundation Node-RED project. It was founded by Nick O’Leary, co-creator of the Node-RED project and is backed by Open Core Ventures.

The platform will provide multi-tenancy, enterprise-ready authentication integration, auditing, compliance and observability. It will provide a seamless low-code developer experience whilst offering integration with version control and CI systems.

FlowForge is an all-remote company, with the current team based in Europe. We want to build a company that provides a healthy, supportive and enjoyable place to work. Our company values are available in our public handbook.
