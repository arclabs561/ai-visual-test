What is Cookie Control?



Cookie Control presents clear information to the users on how their behaviour will be tracked and offers simple controls for explicitly granting and revoking consent.




The Original, Universal Solution For Cookie Compliance Updated To Meet GDPR Requirements.


With an elegant user-interface that compliments the look and feel of your site, Cookie Control is a mechanism for controlling user consent and the use of cookies. Trusted by thousands of organizations, and seen by millions of users each day; the solution presents clear information to the users on how their behavior is to be tracked and offers simple, intuitive controls for explicitly granting, and revoking consent.


Apart from the stand-alone version of the tool, we offer plugins for Wordpress, Joomla, Drupal.

Cookie Control FAQs






Does Cookie Control offer guides, tutorials and or customer support?




We offer detailed and comprehensive documentation and examples which help to install and configure the tool according to your needs.


    

  • Cookie Control Community edition includes active Community support
    • 

  • Cookie Control Pro and Multi-site Pro editions include Helpdesk personal one-to-one support as well as active Community support
    • 









What is Cookie Control generally used for?




Cookie Control is a GDPR compliant tool used for communicating your website's cookies activity to your visitors in a clear and transparent way. It is a tool to assist you in acquiring user consent on how you can use their personal information efficiently.










What are some applications Cookie Control is commonly used in tandem with?




Websites, Google Tag Manager and Content Management Systems.








Does Cookie Control integrate with any other apps?




Cookie Control has a flexible API to connect with any third-party application.










Does Cookie Control offer multi-user capability (e.g. teams)?




There is no limitation to the number of users who can use the service.








What platforms does Cookie Control support?




Cookie Control can be installed on any platform except native app ones. It is a JS module that can run on any website and it is technology independent. We also offer plugins for Wordpress, Joomla and Drupal.










Does Cookie Control offer an API?




Yes, Cookie Control offers a flexible API.








Who are the main user groups of Cookie Control?




Marketing professionals, IT admins, Website admins, Web developers, Data Protection Officers, Compliance professionals, GDPR professionals, Website development agencies, Marketing agencies, Advertising agencies, Advertising professionals
