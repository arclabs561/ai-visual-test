Mozilla Balder Monkey print


This is a fun project with Mozilla (Firefox) for their new WebAssembly standard being developed in a W3C Community Group whose members include Mozilla, Microsoft, Google and Apple. It's my fourth project with the Java Script team. The image is a collage of antique open source art reflecting the open source code.

We made the Screen print edition, stickers, and a ton of T Shirts!

Mozilla Baldr Monkey Project
18x24", 6 color screen print on heavy black stock
signed/numbered edition of 120
