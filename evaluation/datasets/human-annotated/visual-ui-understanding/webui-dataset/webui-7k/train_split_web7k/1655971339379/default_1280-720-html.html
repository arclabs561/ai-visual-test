   <title>FileZilla Server 1.4.0-rc1 released</title>
   <link href="https://filezilla-project.org/"/>
   <id>filezilla-project.org:2022-04-20T12:58:00Z</id>
   <updated>2022-04-20T12:58:00Z</updated>
   <summary type="xhtml">
     <div xmlns="http://www.w3.org/1999/xhtml">
       <h4>Fixed vulnerabilities:</h4><ul><li>MSW: the installer doesn't rely on the PATH environment variable to find the tools its needs, but refers to them absolutely, to avoid hijacking.</li>
</ul><h4>New features:</h4><ul><li>The size of the TCP buffer sizes on the sockets used for data transfers can now be specified</li>
<li>Configuration files are now tagged with a &quot;flavour&quot; and a version number. The Server will refuse to load configuration files with a different flavour than its own or with a version higher than its own. The server's option --config-version-check can be used to control this functionality: if specified, the server checks the versioning, performs the required action and then exit, unless its action is 'ignore'. If the action is 'error', it just checks whether the versions are ok. If the action is 'backup', then a backup of the files is made if the versions are not ok. The parameter --config-version-check-result-file is used to specify a file in which the result of the version check has to be put. If the file contains 'ok', then everything went file. If the file contains 'error', then there was an error. If the file contains 'backup', then a backup was made. The installer makes use of this functionality.</li>
<li>Admin UI: the selected log entries can now be copied to the clipboard, in CSV, HTML and plaintext formats through the context menu</li>
<li>Admin UI: the settings dialog layout has been changed to accomodate for future other protocol settings, factoring out the settings that are common to all protocols.</li>
<li>Admin UI: adjusted borders and spacing to look better on HiDPI displays.</li>
<li>Admin UI: preserve the fingerprints of the previously connected servers. The connection dialog gives hints when inputing the host and port.</li>
<li>Log files can optionally be rotated daily instead of by size</li>
<li>Added option to specify a default user to impersonate if a user logs in with an account that does not use impersonation</li>
</ul><h4>Bugfixes and minor changes:</h4><ul><li>MSW: The installer not detects and rejects 32bit Windows</li>
<li>MSW, Admin UI: No more double error message when a validation error occurs</li>
<li>Admin UI: Solved a crash and fixed other bugs related to minimzing the main window to the notification area</li>
<li>Server: --write-config option now also updates the users and groups configuration files</li>
<li>Server: the log contains more detailed info about which configuration files have been saved</li>
<li>Admin UI: the controller used for editing numbers now correctly accepts negative integers</li>
<li>The network config wizard's text has been updated to be more explanatory and intuitive</li>
<li>Self signed certificates don't require a 2nd level domain anymore</li>
<li>Admin UI: the system user is now always at the top</li>
<li>Admin UI: more meaningful message if the password is empty</li>
<li>Admin UI: message dialogs now always have a reference to the top window</li>
<li>FTP: QUIT needs to respond with 221, not 200</li>
<li>Bug fixes to the internal HTTP library</li>
<li>MSW: the installer now correctly displays the progress bar in all cases</li>
<li>Fixed a confusing error message in some situations if trying to list non-existing directories</li>
</ul>
     </div>
  </summary>
