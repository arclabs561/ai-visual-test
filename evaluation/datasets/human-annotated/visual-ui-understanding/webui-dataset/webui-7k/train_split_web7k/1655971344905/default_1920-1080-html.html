baserCMSとは？

Webサイトを自由にカスタマイズできるCMS（コンテンツ・マネジメント・システム）です。
無料で使える国産のオープンソース・ソフトウェアとして、直感的な操作性と高いメンテナンス性、安全性を実現。
さまざまなサーバーで動作可能で、簡単にインストールできます。

  • 固定ページやブログ、フォームをまとめて管理
  • メールフォームや新着ブログなどのプラグインを標準装備
  • 国産のソフトウェアなので安心・安全のセキュリティ

FEATUREbaserCMSだからできること

  • Webサイト制作の
    使い始めに強い

    直感的な操作と高いメンテナンス性を実現

    メールフォームやブログ（複数ブログ）といったサイト制作に定番な機能が標準装備されているから、インストール後にいろいろ設定をしたりプラグインを追加しなくても、いきなり使えます。設置も簡単だから、制作に素早く取り掛かれます。全体構造を把握しながら素早く設計できる、Web制作者の使い始めに強力なCMSです。大規模なサイトや、導線が複雑なサイトほど重宝します。

  • Webサイトの
    メンテナンスに強い

    サイト運用を考えた使い続けに強力なCMS

    普段Web制作を行っている開発メンバーだからこそ、サイト運用を考えた、使い続けに強力なCMSです。Webアプリケーション脆弱性検査サービスの「VAddy」による脆弱性検査をクリアしているので、安全に利用できます。Webサイトのコンテンツが増やしやすいように設計され、内的SEOとしての重複コンテンツ問題への対策（URL正規化のためのcanonical属性を自動挿入など）も考えられたしくみです。

  • クリエイターの力
    で成り立つコミュニティ

    スキルとコードをシェアしあう仕組み

    baserCMSは、カスタマイズ性が高いのが特徴ですが、公式ガイドなどで少し学習が必要となります。
    質問、不具合のご報告、改善要望などができる交流サイトであるユーザーズフォーラム、情報発信、運営、制作・開発を行うbaserCMSユーザー会、最新情報や勉強会などのイベント情報を配信しているbaserメルマガなど、コミュニティも充実しています。
