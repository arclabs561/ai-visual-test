Antimber is a collection of themes that I built for my current Arch Linux, i3wm and Polybar environment.

There are currently 2 themes. Arboria is a minimalist, forest green set up using i3wm, dunst and polybar. Feówerscýte is an iteration upon Arboria and is stark, monochrome and makes heavy use of the Geometric Shapes unicode block for system notifications.

Antimber also has a central install script used to quickly install or switch the currently used theme.
