Tools of the Technocracy

Tools of the Technocracy is a series of articles to bring to light the systems that are being built to ensnare people. Instead of focusing too much on specific threats, the goal is to give a "forest for the trees" perspective.
People need to have an awareness of what these technologies can do, and how they can build into each other and create feedback loops. With this knowledge we can all work together to avoid these pitfalls.
Also available on Substack

Interverse

Interverse is a system for sites to advertize their content and connections.
The idea is that once enough people are using this system truly decentralized search engines and discovery services can be built on top of the system.
