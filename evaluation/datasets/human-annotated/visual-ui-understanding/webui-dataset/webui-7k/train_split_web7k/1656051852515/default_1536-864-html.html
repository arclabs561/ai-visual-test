  • Comment ça marche

    27 octobre 2011, par ben.spip

    Le site Grml.eu utilise la mutualisation de SPIP. Pour créer un site, choisissez un nom de site et rendez vous sur l’url NomDusite.grml.eu
    Entrez y le mot de passe magique "ecureuil" ( en minuscule sans guillemet) et vous allez installer un SPIP tout neuf.
    Attention les sites sur grml.eu sont effacés régulièrement.
