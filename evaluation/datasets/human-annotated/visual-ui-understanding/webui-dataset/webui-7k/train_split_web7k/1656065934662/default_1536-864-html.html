Get more for less

EmailOctopus is free for up to 2,500 subscribers. And free plan users get access to all the same features that Pro plan users do, including segmentation and automation.

GetResponse offers a free plan, but only up to 500 subscribers. And free plan users cannot schedule campaigns, set up welcome emails or use list segmentation.
