The 9wm Window Manager

9wm is an X window manager which attempts to emulate the Plan 9 window manager 8-1/2 as far as possible within the constraints imposed by X. It provides a simple yet comfortable user interface, without garish decorations or title-bars. Or icons. And it's click-to-type. This will not appeal to everybody, but if you're not put off yet then read on. (And don't knock it until you've tried it). the full README

An updated 9wm is available here! Dhog's last pre-1.2 package is still here.

usage: 9wm [-grey] [-version] [-font fname] [-term prog] [exit|restart]

9wm has an undocumented -nostalgia option, for a BLIT cursor, which John Mackin insisted on.

There are several window managers derived from 9wm: rio is an update as part of Plan 9 from User Space, while w9wm, lwm, aewm, larswm and windowlab were based on or inspired by 9wm.
