./textproc/txt2tags [utility to turn simply formatted text into markup]
[+] Add this package to your ports tracker

Version: 2.6, Package name: txt2tags-2.6
Maintained by: Matthias Kilian
Master sites:
  • https://storage.googleapis.com/google-code-archive-downloads/v2/code.google.com/txt2tags/ (Download)
Description
txt2tags is a format conversion tool written in Python that generates
HTML, XHTML, SGML, LaTeX, Lout, Man Page, MoinMoin, Magic Point and
PageMaker documents from a single text file with minimal markup.
