Security

We are PCI-DSS certified (Payment Card Industry Data Security Standard), the industry standard for internet-based financial services transactions. All data is encrypted using SSL technology so that payment account numbers are never viewable in any part of the service.

Financial Account Information Storage

Storing account information is optional and not required to register or use the service. Storing payment account information speeds check out and is required to perform some special functions such as automatic replenishment of food service accounts, however, it is never required.
