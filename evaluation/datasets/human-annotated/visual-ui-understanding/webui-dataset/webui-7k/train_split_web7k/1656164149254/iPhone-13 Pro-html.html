How is the data calculated?

Where does the money come from? IATI data taken from the IATI Registry each night.

Where does the money go? (Sectors) IATI data taken from the IATI Registry each night. Sectors are CRS 3 digit sector codes.

Heatmap A count of IATI activities that contain specific coordinates in their location data. NB - only some IATI activities currently contain this data.

Project list This list shows you total commitments for each activity and the percentage spent so far, sorted by the most recent at the top. Full black bars may signify data quality issues where published data is missing commitment and/or transaction information.

Typically this data will have been updated from the IATI Registry everyday at midnight GMT.

How are exchange rates calculated? We currently convert to USD using the exchange rate of the date specified in the value-date attribute.
For other currencies, the USD value is converted using today’s exchange rate.

Please refer to the FAQ for more information about currencies and exchange rates.

Data Investigators, we need you! If you find anything out of place, please contact the development team.
d-portal.org helps you explore IATI data.

It provides a search function and information by country or by publisher on development activities and budgets published to the International Aid Transparency Initiative (IATI).

d-portal is currently in BETA. While publicly available, d-portal is not considered finished. Please feedback if you experience any bugs and missing features.

If you have any queries relating to the data itself, which is owned by the publisher, please contact them here.

If you have any queries about how the data is shown in d-portal, or how up to date the data is, please see the FAQ or contact the IATI support helpdesk support@iatistandard.org
