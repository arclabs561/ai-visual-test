This is the 421st issue of the World Wine News publication. Its main goal is to inform you of what's going on around Wine. Wine is an open-source implementation of the Windows API on top of X and Unix. Think of it as a Windows compatibility layer. Wine does not require Microsoft Windows, as it is a completely alternative implementation consisting of 100% Microsoft-free code.


Wine 7.11

It isn't even July 11th yet, and I have already been caught whining about the heat here in Minnesota... in other news, Wine 7.11 arrived last Friday bringing the following:

  • Android driver converted to PE
  • Zero-copy support with GStreamer
  • High Unicode planes support in case mappings

You see what I did there? July 11th and 7.11, wine and whine? It was against my better judgement, but I did it.
