FEATURESEO Dash!の特徴

  • 2002年からSEOに携わっているSEOのプロフェッショナルが施策を監修
    Googleの検索エンジンが日本にリリースされた当初より、SEOに従事し、アルゴリズムの歴史を熟知しているプロが施策を監修します。そのため、Googleのリリース情報や、検索業界の旬な情報を元に、検索トレンドの流れや動きを想定した施策を設計します。
  • 海外の検索トレンドや施策を日本の環境に合わせてローカライズ
    SMX(Search Engine Expo)やPubconなど、検索エンジン業界のトレンドやアルゴリズム、施策などの情報をそのまま適用するのではなく、日本の検索市場とアルゴリズムに合わせて、最適な形でローカライズし、お客様ごとに合った施策をご提供します。
  • SEO=検索順位ではなくユーザーの検索体験と産み出される価値にフォーカスした施策を提案
    SEO=集客したユーザーの検索ニーズを満たすことで、ユーザーの検索体験を向上し、そこから産み出されるビジネスチャンスや機会を創出する施策と捉えています。そのため、弊社のSEOは、ユーザーの検索ニーズと求められている答え、そして施策対象サイトが提供できる価値をすり合わせるところからスタートします。
  • サイトの規模や競合のアプローチ状況に合わせ最も適したSEOの基盤を設計
    単にSEO上実施したほうが良い施策を闇雲に提案するのではなく、サイトのコンテンツや、ビジネスの内容、競合の施策状況や、検索市場に対するアプローチなど、状況を多角的に判断し、貴社に合ったベストなSEOをご提案します。
  • WEBサイトと検索エンジンの親和性を重視
    検索エンジンの考え方、ユーザーの検索ニーズ、コンテンツの状況を考慮し、検索エンジンが最適な形で貴社サイトをクロール、インデックスするよう、バランスの取れたSEOを実施します。
  • アルゴリズムの基本となる普遍的な施策を実装
    アルゴリズムは常に進化していますが、アルゴリズムのベースは変わっていません。そのため進化するアルゴリズムに合わせて、サイトを成長させて行くためには、ベースとなる基礎構造がしっかりと整っていることが必要不可欠となります。本サービスは、サイトの構造を0ベースで見直し、アルゴリズムのベースに沿ったSEOの基礎を整えるため、サイトの基礎体力を強化することが可能となります。

MEASURE施策内容

  • #01

    狙うべきキーワード市場を設計

    MEMO
    ユーザーの検索するキーワードがビジネスに直結し、保有するコンテンツがユーザーの検索意図に対する答えとなる領域=SEOでアプローチするべき検索市場

    キーワードを設計する際、検索ボリュームだけを意識した設計とするのではなく、ユーザーが検索するキーワードの検索意図と、意図にマッチしたコンテンツを念頭に設計します。本設計を実装することで、WEBサイト全体が、検索結果からの玄関口となるだけでなく、ユーザーの検索意図を満たすことになるため、結果としてWEBサイトの目的=ビジネス上のゴールに貢献することになります。

  • #02

    検索ストーリーを意識した
    キーワード設計

    MEMO
    SEOを設計する上で重要なポイントは、ユーザーの検索ストーリーを考慮し、ストーリーを想定したキーワード市場にアプローチ

    ユーザーとWEBサイトの接点を考慮する際、ユーザーの認知度がない状態については、サイトの目的やサービスにダイレクトに辿り着く検索行動はほぼないと考えます。そのため、検索ユーザーが目的にたどり着くための検索ストーリーを考慮した上で、キーワードを設計いたします。設計の際には、間接的に貢献するキーワードと、目的に直接貢献するキーワードの二つの軸を念頭に置いてキーワードを設計致します。

  • #03

    現状サイトの課題を抽出

    MEMO
    最新アルゴリズムへの対応、マシンリーダブル、サイト構造の最適化により、SEOと親和性の高いサイトを構築

    ユーザーの検索ニーズを理解したコンテンツ、ユーザーが迷うことなく目的の情報に辿り着ける、ならびにGoogleにも理解しやすいサイト構造(HTMLマークアップや、タイトル、見出し、内部リンクなど)に整えることで、ユーザーの検索体験を最大化=Googleからも評価されるコンテンツへと進化させます。

  • #04

    課題を解決するための施策提案

    MEMO
    サイト全体の現状把握を行い、多角的な視点でサイトの改善方針をご提案

    現状のお客様のWEBサイトの順位状況、サイト流入状況、コンテンツ状況、競合他社のサイト状況を確認し、課題点を洗い出し、サイトの改善方針をご提案いたします。
