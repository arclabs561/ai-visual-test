About Machine-learning-nederland
English (USA)

Email list for concise announcements of meetings, talks, positions, etc. that are related to academic machine learning in the Netherlands

To see the collection of prior postings to the list, visit the Machine-learning-nederland Archives.

Using Machine-learning-nederland
To post a message to all the list members, send email to machine-learning-nederland@list.uva.nl.

You can subscribe to the list, or change your existing subscription, in the sections below.
