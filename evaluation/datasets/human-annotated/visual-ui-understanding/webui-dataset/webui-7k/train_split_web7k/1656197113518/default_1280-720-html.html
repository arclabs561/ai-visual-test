Plugins for continuous integration servers

To get a free 30 days evaluation license key for a fully functional version of YouMonitor plugin, please install the plugin in your CI server and click Get free evaluation license key link on plugin configuration page.

YouMonitor for Bamboo
Compatible with Bamboo 6.1 - 7.2*
Download .obr plugin
YouMonitor for Jenkins
Compatible with Jenkins 2.54 - 2.293*
Download .hpi plugin
YouMonitor for TeamCity
Compatible with TeamCity 2017.1 - 2021.1*
Download .zip plugin

* Plugins support monitoring of 32-bit and 64-bit Java processes on Windows x86/x64, macOS arm64/x64, and Linux x86/x64.

YouMonitor UI

YouMonitor UI does not require license key to run. Installed UI copy allows to profile and monitor builds which you run from command-line or from within IDE.
