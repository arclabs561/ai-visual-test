Shishi and Generic Security Service (GSS)

Shishi is our Kerberos V5 implementation, which is used by application through the GSS-API framework.

GSS is our implementation of the GSS-API framework. Currently it support the Kerberos V5 mechanism (through Shishi) but it is flexible enough to support any mechanism.

Please see the Shishi homepage and the GSS homepage for more information.
