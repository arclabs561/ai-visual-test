为世界杯让路！2022-23赛季西甲联赛时刻组织出炉：年末休赛近2月

6月23日，西甲联盟官方发布了2022/23赛季西甲联赛时刻组织。依照方案，新赛季西甲将于8月12日拉开帷幕，最终一轮则在6月4日开赛。此外，新赛季西甲将有三个阶段的间歇期，分别为9月19日至27日，欧国联最终两轮小组赛；11月9日至12月29日，卡塔尔世界杯和圣诞节；3月20日至28日，国家队竞赛。
