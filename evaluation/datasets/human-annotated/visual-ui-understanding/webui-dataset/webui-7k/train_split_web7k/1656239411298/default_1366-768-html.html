会社概要

株式会社Itsukiは、業務システムやWebアプリケーションの受託開発を行うベンチャー企業です。

当社の特徴は、フロントエンドフレームワークを用いたWebアプリの受託開発を行っていることです。顧客の要望に応えてAPIやUXのコンサルティングも手掛けるほか、週1回から月1回の頻度で顧客との定例会を実施し、運用までを一環して担当しています。

Itsukiでは、実際にサービスを使用する顧客企業の営業担当者やカスタマーサクセス担当者から話を聞くなど、ユーザーに寄り添った開発を行う姿勢を重視。顧客に言われた通りのものをつくるのではなく、ユーザーが「どうなりたいのか」に耳を傾け、ITの専門家として最適解を提案・提供しています。

会社の魅力

株式会社Itsukiの魅力は、専門性を磨きながらも開発の幅広い工程を経験し、柔軟にキャリアを築けることです。

フロントエンドフレームワークを専門とする当社は、需要が高くモダンなフレームワークを使用しており、新しい情報を積極的にキャッチアップできる環境です。 社内は少数精鋭のチーム体制であるため、開発における全工程を経験できるのも魅力の一つ。上流の設計提案から運用改善まで、幅広い経験を積める職場となっています。

経験を積んだ先のキャリアパスは幅広く、フロントエンド全般のスペシャリストになる道もあれば、希望と適性に応じて別の職種へのキャリアチェンジも可能です。職種の例としては、WebディレクターやWebデザイナー、サーバーサイドエンジニア、フルスタックエンジニアが挙げられます。

会社の展望

Itsukiは「無機質な情報から、暖かく便利な世界へ」をビジョンに掲げ、フロントエンド開発を通して世界を便利にすることを目指しています。

そのために、市場の伸びしろがあるAPI領域をさらに強化していくとともに、自社サービスの社外への展開も視野に入れています。 事業拡大に向けては組織の拡大も図っており、現在は新しいメンバーを募集中。2021年10月時点では、代表を含む5名のエンジニアが2チームで稼働していますが、2022年3月末までには8名増員して計13名4チームの体制を目指していきます。

会社とプロダクトがともに成長期を迎えているItsukiは、「良いものをつくりたい」という思いに共感する方と働きたいと考えています。コアメンバーとして一緒に組織づくりをしたい方は、ぜひ当社にご応募ください。
