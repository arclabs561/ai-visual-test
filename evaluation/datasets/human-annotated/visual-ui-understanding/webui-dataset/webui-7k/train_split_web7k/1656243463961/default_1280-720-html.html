罗格·维维尔(RogerVivier)的全新手机链包正被抢购一空。

2022-06-26 19:36:45家居用品

迷你手袋热潮正在蓬勃发展，罗格链包在这股热潮中，全新抢购手机现代人不可或缺的手袋必须成为主流力量。正被许多奢侈品牌推出了一系列迷你手袋。


比如香奈儿香奈儿(Chanel Chanel)的菱形链包、罗格链包古奇(Gucci)的旧花包，全新抢购手机以及巴黎巴黎(Balenciaga)家族的极简式黑白手袋。正被法国鞋类品牌罗格维维尔(RogerVivier)本季度还推出了一款新的迷你手袋--BrocheVivier。



2021年春夏系列由创意总监盖拉多费洛尼(GherardoFelloni)经营，罗格链包全新抢购它改变了经典的方形扣设计。花束迷你手袋、手机斯特拉斯巴克勒高跟鞋、正被罗格链包花斯特拉斯手镯等都被华丽的钻石设计所取代。这一季的热手袋还配备了凡尔赛闪光灯钻扣，全新抢购房车两侧的肩带也都是闪光钻石马赛克，手机以及牛皮材质对比，简单且不失质感。


这款手袋还包括许多颜色选项，包括经典的奶油白色和黑色，明亮的浅蓝色和紫色，以及新年限量红色。但官方网站显示，这一系列手机包已经售罄。
