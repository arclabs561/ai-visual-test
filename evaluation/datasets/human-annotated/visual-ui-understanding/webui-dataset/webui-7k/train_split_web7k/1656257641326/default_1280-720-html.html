萌德成为 Tommy Hilfiger 全球品牌大使！

2022-06-26 23:33:02商品分类

　　来源：萌德下水道男孩

　　原标题：萌德成为 Tommy Hilfiger 全球品牌大使！

　　今日，全球品美国时尚品牌 Tommy Hilfiger（汤米·希尔菲格）官宣加拿大鲜肉 Shawn Mendes（肖恩·门德斯）成为品牌最新的全球品牌大使！萌德

　　其实在前不久，全球品Met Gala 的红毯上，萌德Shawn Mendes 所穿的就是来自 Tommy Hilfiger 赞助的礼服，全球品这套双排扣礼服，萌德全球品采用的就是 Tommy Hilfiger 最经典的红蓝配色。

　　在此前，萌德Shawn Mendes 也多次和品牌合作，全球品萌德展现了品牌洋溢着青春的一面。

　　Tommy Hilfiger 该品牌由同名设计师创立，全球品红白蓝是 Tommy Hilfiger 品牌的标签色，萌德也是美国的国旗色，全球品所以这个品牌可谓美式休闲品牌的经典代表，萌德象征着美式休闲和运动风尚。

　　它和美国品牌 CALVIN KLEIN  一样都同属 PVH 集团旗下，两个品牌都坚持着美式时尚为核心，也一直有不少的追崇者。

　　作为一个以学院风为品牌 DNA，融入帅气的街头元素的经典时尚品牌，又带有些许海军元素的 Tommy Hilfiger 拥有非常强烈的品牌风格，鲜明却并非张扬，也成为了美式时尚的领军人。

　　品牌所代表的是当今美国街头年轻一代最为普遍的常态装扮。

　　最经典的合作就是在布兰妮 Baby One More Time 首专巡回演唱会上，Tommy Hilfiger 成了主办方与赞助商，在当时两者的形象和气质真的很搭配。

　　一直以来，Tommy Hilfiger 都喜欢和各个时期最火最新鲜的新人面孔合作，从布兰妮到碧昂丝，再到赞达娅和赛车手汉密尔顿，嘻哈歌手杰克·哈洛都曾是与该品牌合作过的明星。

　　而我觉得 Shawn Mendes 也是非常适合这个品牌的，恭喜他了！
