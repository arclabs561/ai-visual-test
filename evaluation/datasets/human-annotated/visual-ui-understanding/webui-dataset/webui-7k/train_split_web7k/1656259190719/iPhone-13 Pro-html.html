Lisensi

7-Zip merupakan aplikasi open source. Sebagian besar kode program berada di bawah Lisensi GNU LGPL lisensi. Kode unRAR memiliki lisensi campuran antara: GNU LGPL + pembatasan unRAR. Pelajari informasi lisensi berikut: lisensi 7-Zip.

Anda bisa menggunakan 7-Zip pada semua komputer, termasuk komputer untuk organisasi komersial. Tidak perlu mendaftar atau membayar untuk menggunakan 7-Zip.

Fitur utama 7-Zip

  • Rasio kompresi tinggi pada format 7z dengan kompresi LZMA dan LZMA2
  • Format yang didukung:
    • Kompres/ekstrak: 7z, XZ, BZIP2, GZIP, TAR, ZIP dan WIM
    • Hanya ekstrak: AR, ARJ, CAB, CHM, CPIO, CramFS, DMG, EXT, FAT, GPT, HFS, IHEX, ISO, LZH, LZMA, MBR, MSI, NSIS, NTFS, QCOW2, RAR, RPM, SquashFS, UDF, UEFI, VDI, VHD, VMDK, WIM, XAR dan Z.
  • Untuk format ZIP dan GZIP, 7-Zip menyediakan rasio kompresi yang lebih baik 2-10 % dibanding rasio yang digunakan oleh PKZip dan WinZip
  • Enkripsi AES-256 yang kuat pada format 7z dan ZIP
  • Kemampuan self-extracting (otomatis terekstrak) pada format 7z
  • Integrasi dengan Windows Shell
  • Pengelolaan berkas (File Manager) yang andal
  • Powerful command line version
  • Plugin untuk FAR Manager
  • Tersedia dalam 87 bahasa

7-Zip bisa bekerja dalam Windows 10 / 8 / 7 / Vista / XP / 2016 / 2012 / 2008 / 2003 / 2000 / NT.

p7zip - port versi baris perintah 7-Zip ke Linux / Posix.

Pada halaman 7-Zip di SourceForge anda bisa mendapatkan forum, laporan bug, dan sistem permintaan tambahan fitur.
