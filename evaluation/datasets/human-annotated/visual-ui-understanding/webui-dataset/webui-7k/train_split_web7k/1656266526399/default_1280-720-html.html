スニーキング&隠れる

忍び足で敵の背後から近づき、必殺の攻撃を喰らわせる『スニーキングキル』。もし気づかれてしまっても、敵をふりきれば様々な場所に隠れることができる。

Game Feature「スニーキング＆隠れる」

戦闘&燃やす

少ない弾薬を節約する方法のひとつとして、マッチで敵を燃やすことができる。敵の足を撃って転倒させ、倒れこんだところに火をつけたり、近接する複数の敵を巻き込んで燃やすことが可能。

Game Feature「戦闘＆燃やす」

ワイヤートラップの解除

フィールドには大小様々なトラップが仕掛けられ、プレイヤーの不意を襲う。中には解除することができるトラップもあり、成功するとアガニボルトを作るのに必要なトラップパーツが入手できる。

Game Feature「ワイヤートラップの解除」

ワイヤートラップに掛かる

トラップに掛かるとダメージを負う。

Game Feature「ワイヤートラップに掛かる」

センサー爆弾解除成功

フィールドには大小様々なトラップが仕掛けられ、プレイヤーの不意を襲う。中には解除することができるトラップもあり、成功するとアガニボルトを作るのに必要なトラップパーツが入手できる。

Game Feature「センサー爆弾解除成功」

センサー爆弾解除失敗

解除操作を失敗すると爆弾が爆発、ダメージを負う。

Game Feature「センサー爆弾解除失敗」

アガニクロスボウ＆アガニボルト

アガニクロスボウは効果の違う5種類のアガニボルトを使い多彩な攻撃が可能。工夫次第で戦闘を非常に有利に進められる。アガニボルトは収集したトラップパーツを使い、自ら作ることもできる。

Game Feature「アガニクロスボウ＆アガニボルト」

ショック・ボルト

敵を一定時間しびれさせるボルト。映像では動けなくなった敵にマッチを使い、燃やしている。

サイコブレイク公式サイトGame Feature「ショック・ボルト」

フラッシュ・ボルト

強い光を発し、敵の目を眩ませることができる。

Game Feature「フラッシュ・ボルト」

マイン・ボルト

直接敵に撃ち、爆発させる他に壁などに撃ち、敵をおびき寄せて爆発させる使い方もできる。

サイコブレイク公式サイトGame Feature「マイン・ボルト」

フリーズ・ボルト

敵を凍らせることができる。凍ったところで攻撃を加えることや、一定時間経過することで粉々に砕ける。

サイコブレイク公式サイトGame Feature「フリーズ・ボルト」

ハープーン・ボルト

敵を串刺しにでき、壁などに固定できる。刺さったボルトは回収できる。
