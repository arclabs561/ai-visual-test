tools to help people translate books

Inchword has been used by over 300 translators, editors, and reviewers, to translate books into thirty languages.

how it works

  1. Author uploads text, with clarifications. (details…)
  2. Translator translates one sentence at a time. (details…)
  3. Author answers Translator’s questions, now visible to future Translators. (details…)
  4. Reviewers offer improvements. Translator improves until done. (details…)
  5. Editor makes final improvements. (details…)
  6. Manager oversees entire process. (details…)
  7. Reviewers can vote to choose the Translator. (optional) (details…)
