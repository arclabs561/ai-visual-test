年に一度

定期報告をする場になってきましたが、そういった場はもはや貴重なので、
このためだけにサーバーの年会費を払い続ける理由になります。ちょっと整理したいですけどね。そろそろログとか。

また一年、ありがとう御座いました。
ご覧になってくださり、お祝いのお言葉をいただいたりと誠にありがとう御座います。
今年はすっかりお祝いの日というより月末の〆切にハアハア言っている日という感じで、
いただいたメッセージでハッと気付いて宅配ピッツァなど頼み、楽しい一日を過ごしました。

この一年…。コロナウィルスについては、一年前ぐらいは一年ぐらいかかるかなあというなんの根拠も無い希望を持っていたのですが、今や「あと何年かかるかなあ」というぼんやりとした気持ちです。
個人レベルでは、ほとんど誰にも会わない生活はそこまで苦ではないのですが、仕事のためにする旅行が出来ないのは少し困っています。
今年に入って半年は、なんと８割方仕事の事を考えていたので、もう８月ですよと聞くと御冗談をと壁に向かって笑いたくなります。
めちゃくちゃバリバリいっぱい仕事してるわけでは全く無くて、単に私の作業が遅いんですねこれは。おやおやおや。でも楽しいですよ。難しすぎてちょっと、十分に出来ることは一生無いと思うけど。だからもうちょっとやってみようと思います。
あと今年半分でその他に何をやらなければならないかというと、2022年1月21日に発売されるエルデンリングのために仕事を巻いて進め、PS5を入手する事が最優先となります。自信無いな。どちらも。PS5、人口の3倍ぐらい作ってくれ。頼むよ本当に。

また一年、皆様が健やかでいられるよう願っています。
私ものびのび生き生き健やか太郎でいたいですね。なんそれ。

今年もこの日

年に一度の近況報告日のようになってきた、サイト開設日&わたくしの誕生日です。
メールなどでお祝いのお言葉をありがとう御座います！
お返事少々お待ちくださいませ。

近況といえば、今年は主にコロナウィルスの世界的感染拡大により、人類の厄年ですねという有様ですが、さいわいにも私個人はそこまで影響を受ける事無くぼんやりと暮らしております。
とにかくどこか旅行へ行く、外出する、という事がほとんど無くなりましたので、例年にくらべ季節の移り変わりにも鈍感で、明日から8月なんて思えないぐらいです。
仕事だけは楽しく忙しなく存在するので、それだけは幸いです。
相変わらず毎日描いたりなんだりしております。

毎朝6時25分にNHKでラジオ体操が流れるんですが、それがすっかり習慣になり、そこそこ健康的。休日も朝早く自主的に起きるとあまり罪悪感を感じ無くて良い感じです。でも昼寝は大事。
最近はインプットが漫画・小説寄りになっていて、多い時は一日漫画30冊、小説3冊程度を読んだりする日々です。
中国SFが気になるので、まずはアンソロジーや短編集からね、とチャレンジしています。
悪役令嬢を端から嗜み、星新一のショートショートを間につまんでいると、情緒がまるでジェットコースター。
インプットがゲームや映画に寄ると、これらを全く読まなくなるので、興味があるうちに自分を甘やかすだけ甘やかし、摂取できるだけ摂取するようにしたいなあ。
インプット：アウトプットを9:1ぐらいで生きていきたいけど、締め切り前には1:9ぐらいになるの、人生のバグ。

それではまたいずれ。
心身ともに健やかにお過ごしください。

近況と

昨日はこのサイトの誕生日でした。今日も見てくださってありがとう御座います。
生活に追われていますが最近は、いや、まだ圧縮したりメリハリをつけてやりたい事を増やせるよな、という気持ちにもなってきました。実際できてはいませんが、この意識だけでも継続できるように。

私の誕生日お祝いのメールなども頂いてしまいとても嬉しかったです(返信少しお待ちくださいませ！)。ケーキを２個も食べてしまった。最近「自分の誕生日、あまり意識しないので普段は食べないカップ麺を食べたら、ちょうど誕生日だった事もあります」と友人に言ったら「えっ」という反応をされたので、ちょっと意識しておいしいものを食べたりしました。この場合意識しているのか？カップ麺をめったに食べないのはたしかにそうなのですが、インスタント麺のほうが好きというだけなのです。そして記念日においしいものや特別な事をしたり、逆にかわらない日常を過ごしたりする事はとても好きな概念です。自分の事だと適当になりがちですが、今後はちゃんと演出していきたい。
最近このように日記のような文章を書きたい気持ちになる事も多く、そのたびに「このサイトのログインページどこだっけか」(最近PCを変えたのです)で諦めていたので、すぐ書けるように設定しました。

このお題を数年越しに描きました。大変遅くなってしまいました。FGOは装飾の物量が多いので楽しくも難しいなと思いました。
もうひとつオリジナルでリクエストを頂いていたのですが、自分の描いた創作キャラクターの資料どこだっけ？と筆が止まっています。こちらもまたいつか。

メールフォームを撤去しているのは、フォーム経由でのスパムがちょっと多すぎたためです。
送りやすいと思うのでまた折を見て設置したいと思います。

2018/07/31

雑記

今日はこのサイトの誕生日です。何年目だろう…１６年目ぐらいですかね。
何をするというわけでも無いのですが、インターネットでもあっちこっちふらふらしている身なので、ここはずっと残しておきたいですね。覗いてくださってありがとう御座います。

実は、同じ日に設定してしまった照れ臭さに毎年サイトの誕生日だけ祝っていたんですが、私の誕生日でもあります。
昨日、お会いした方に(明確に誕生日を告げていないにもかかわらず)「正確な日付は知らないのですが、昨年今頃が誕生日だと伺って」とお花とバースデーカードを頂いて、その花を眺めているとああ今日って誕生日なんだな、という気持ちになったので書きました。
家族や友人にお祝いの言葉をもらったり、すてきなプレゼントが送られてきたり、歳を取るごとに穏やかで希薄になっていく７月３１日ですが、それだけにありがたく不思議な事だなあと思います。

酷暑続きですが熱中症などにお気をつけて。
私は先日一週間ほど北海道に滞在しました。
旅行というほどの事ではなく、涼しい地で美味しいものに囲まれながら仕事をしようというしなびた理由が半分です。
肌にまとわりつくような湿気の、あの空気が無いので、とても心地よかったです。
実はしばらくだるさや不眠症が続いていたのですが、滞在一日目に治ったのには笑ってしまった。
因果関係は謎ですが。
年々夏の厳しさが増していくような気がするので、毎年どこか涼しいところに逃げて暮らしたいですね。

(落ち着いたらSDリクエスト頂いた物を描くぞ！マーリン先生の服がどうなっているのかわからず止まっています)

このサイトの誕生日が近付いているのに今年も何もできそうにないふがいなさです。
最近は「来年は趣味の制作をたくさんするんだ…」と毎日思いながらほどほどに働いていますよ。
働くという言葉を言うのが何年経っても苦手で、事実たくさん働いている方よりおそらくずっと働いていない自覚はありますし、いつも遊び呆けて趣味の惰眠を貪っている人間でありたいので、忙しいという言葉を使うのも苦手なんですが、なぜか日々あっぷあっぷしています。夏の怪談に近い。
目下の課題はスプラトゥーン２とゼルダBoWとドラクエ11を遊ぶ時間をどうやって捻出するかです。
これは死活問題です。

今月の頭に軽井沢に行ってきました。避暑とは何か？と避暑地のイメージを幼いころから抱いていた軽井沢に行ってみたかったのです。
涼しくて湿気があまり無くて、とっても避暑しました。また行きたいなあ。

夏は気をつけていてもカジュアル熱中症になりやすいので、ガブガブ水を飲んでくださいね！

メールが先方に無事送信済みでこちらへ返信が無いのであればいいのですが、そもそも先方に届いていない場合が心配です。
