What is IPv6ScopeFinder?

IPv6ScopeFinder™ is a free Windows app that shows the Scope ID of your IPv6 network interfaces so you can use Link Local Addresses.

Overview of IPv6ScopeFinder for Windows

IPv6ScopeFinder 3.00 was released January 11, 2013. It is a freeware product designed to help you quickly find the Scope ID used to communicate with neighboring link local IPv6 addresses.


It shows link local and global IPv6 addresses assigned to each network interface. It also shows IPv4 addresses assigned to each interface.


IPv6ScopeFinder shows you this important information about each network interface:

  • ScopeID (IPv6 interface index)
  • Status (up or down)
  • Interface Type (ethernet, tunnel, etc.)
  • IPv6 and IPv4 addresses
  • Interface Name
  • Description
This program is designed for and has been tested on Windows 10, 8.x, 7  - 32 or 64 bit Operating Systems. Requires GUI, not a command line tool.
