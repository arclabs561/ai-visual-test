About Us

A fanlisting is a web clique that lists fans of a particular subject. Unlike most web cliques, a person does not need a web site in order to join.

The Anime Fanlistings Network is a directory comprised of anime and manga fanlistings.

Welcome to The Anime Fanlistings Network!

You have reached The Anime Fanlistings Network! We are a network site (or link directory) for anime and manga related fanlistings. Formerly a part of The Fanlistings Network, we are now our own site and have partnered with The Fanlistings Network to focus exclusively on anime and manga related fanlistings. From Bleach and Naruto to classics like Sailor Moon, Pokemon and Dragonball — if it's drawn in Japan, you'll find it here!

The Anime Fanlistings Network links fanlistings for many anime and manga subjects (Japanese animation and comics), hosted on many different domains and created by many different webmasters. Having all of these fanlistings categorized in one place makes it easy for you to find fanlistings for subjects you love too, so you can join and meet others who share your interests.

Be a part of it!

Are you interested in creating a fanlisting and getting it listed here? Then head on over to the rules! There we explain exactly what is needed and required from you to be listed at this network.

So who's in charge?

This network is run by a total of 8 volunteers, five of which make up the Senior Staff. They run the network together, under the direction of the Network Owner.

If you have any further questions or comments, please read our FAQ or use our contact form to get in touch with us. Enjoy the network!
