What Do We Measure?

The metrics we measure are around the Time To First Byte (TTFB). This is a useful indicator for the responsiveness of your webserver and network resources involved in serving your site.

TTFB measures the duration from the users browser making a HTTP request to the first byte being returned by the server. As soon as the browser has started receiving content, it can start building up the page infront of the user.
