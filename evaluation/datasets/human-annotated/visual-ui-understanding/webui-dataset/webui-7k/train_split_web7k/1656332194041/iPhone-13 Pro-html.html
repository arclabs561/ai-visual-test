About squeak-doc
English (USA)

This is the mailing list for the Squeak Documentation Team, which is responsible for the creation and maintinence of Squeak Documentation.

To see the collection of prior postings to the list, visit the squeak-doc Archives.

Using squeak-doc
To post a message to all the list members, send email to squeak-doc@lists.squeakfoundation.org.

You can subscribe to the list, or change your existing subscription, in the sections below.

Subscribing to squeak-doc
