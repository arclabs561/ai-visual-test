知道小众美妆醉象和Farmacy吗

2022-06-27 20:15:58女装

据"女装日报"报道，知道醉象致力于向中国引进海外美容品牌的品牌管理公司SuperProgramary从私人股本基金ACG获得了一笔投资，小众美妆具体金额尚未披露。


国内化妆品爱好者可能从来没有听说过超级品牌，知道醉象但他们很可能知道DrunkElephant醉醺醺的大象、小众普通的、美妆农场的、知道醉象Olaplex、小众MilkMakeup等海外少数民族化妆品品牌，美妆知道醉象并通过天猫国际(Tmall International)和其他渠道购买了这些品牌。小众SuperNorary是一家将这些品牌引入中国的公司。



SuperProgramary创始人朱利安·里斯(JulianReis)在接受VogueBusiness采访时表示，美妆他在2016年来到中国时发现，知道醉象中国无法在Instagram上看到美容品牌，小众美妆也看不到海外Sephora最畅销的品牌。海外美容品牌在中国市场并不缺乏雄心，但小品牌很难在中国开设新办事处，在中国市场也缺乏经验。


ACG的执行合伙人JulianSteinberg还表示，他们看到了中国化妆品市场的快速增长和重要性，但意识到西方品牌很难真正管理中国市场的复杂性。


其结果是，Reis于2018年在上海成立了SuperProgramary，主要与年轻的独立化妆品品牌合作，并为中国带来了十多个品牌。SuperNorary在中国和美国拥有200多名员工，该公司将拥有一个拥有所有共同品牌的团队，该团队的4-8名员工将专注于一个品牌。



Reis表示，SuperProgramary不会将美国市场的运作方式直接复制到中国，而是会通过大量的数据分析和社会倾听，从中国消费者的角度思考。


当Supermanary将海外美容品牌引入中国市场时，它将首先在豆印、小红皮书等社交平台上投放大量与品牌相关的内容，以树立品牌意识和口碑。


美国天然护肤品品牌Farmacy是Supermanary在中国推出的第一个品牌，并结合数据分析和市场趋势，选择GREENCLEAN卸妆剂和蜂蜜面膜作为主要社交平台的主要产品与KOL合作，以爆炸性的策略进入市场。


超级普通的合作品牌农场已经被许多小红皮书的用户所评价。


超级合作伙伴品牌MilkMakeup与大量KOL合作在豆印上工作


SuperProgramary的全球总裁苏桂忠告诉VogueBusiness，她认为SuperNormanary知道如何向当地市场传递准确的信息，以及如何组织正确的KOL来完成这项工作。


此外，Supermanary还将扩大天猫、京东、考拉、小红皮书等品牌的销售渠道。


由于几乎所有的超级品牌都是"零残酷"品牌，不进行动物实验，但进入中国市场的美容品牌都需要动物试验，几乎所有品牌都将通过天猫国际进入中国市场，并以跨境电子商务的形式绕过动物实验的要求。


监督公司还将在工作室内推广合作品牌，公司还与李嘉琪和威亚建立了合作伙伴关系。


在一系列措施下，一些超级品牌在中国迅速发展。2019年，Farmacy的销量增长了600%，年销量超过200万瓶。到2020年，Farmacy在中国的销量预计将超过2亿瓶。
