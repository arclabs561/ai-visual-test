Adopter la bonne stratégie pour les métiers

n°201 / Juin 2022

Etre un stratège, c'est choisir. Etre un bon stratège, c'est donc faire les bons choix au bon moment. Et, le cas échéant, il faut savoir changer de choix si la situation évolue. Lorsque les métiers réclament une IT agile, c'est cela : une IT qui s'adapte à leurs besoins, même lorsque leurs besoins changent.
