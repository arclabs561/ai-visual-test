What is it?

Node.js® is a JavaScript runtime built on Chrome's V8 JavaScript engine. Node.js uses an event-driven, non-blocking I/O model that makes it lightweight and efficient. Node.js' package ecosystem, npm, is the largest ecosystem of open source libraries in the world. Node.js Day, previously known as Node.js Italian Conference, it's an international conference dedicated to Node.js. Started and formerly organized by WEBdeBS is now organized by GrUSP, the organizers of jsDay.
