Kunstradio Podcast

[ English Version ]

Seit 10.Oktober 2005 stellt Kunstradio seine Sendungen (ab Anfang September 2005) auch als Podcasts zur Verfügung. Auf dieser Seite finden sich eine kurze Einleitung über Podcasts und wie diese genutzt werden können.

*) Was ist ein Podcast?

Als Podcast (engl. abgeleitet von Broadcast und iPod) bezeichnet man Inhalte, die speziell für tragbare Audio-MP3-Player zur Verfügung gestellt werden. Die Benutzung von Inhalten, die "on demand" (engl. für "auf Abruf") verfügbar sind, wird dadurch für den Benutzer um ein vielfaches erleichtert.

*) Was wird benötigt, um einen Podcast anzuhören?

Hardware:
Ein tragbarer MP3-Player

Software:
Zum Hören eines Podcast wird eine Podcast-Applikation und eine Internetadresse von dem Podcast, der mit der Podcast-Applikation abonniert werden soll, benötigt.

Der Kunstradio Podcast Link:
http://kunstradio.at/kunstradio.xml

*) Wie funktioniert ein Podcast?

Beim Podcast handelt es sich um eine Datei, die in einer für viele Programme lesbaren Form (XML) gespeichert ist. Der Kunstradio-Podcast enthält alle Sendungen plus Titel, Daten und Links (ab September 2005).

Die Benutzer abonnieren einfach diese Datei in ihre jeweilige Podcast-Applikation und haben somit Zugriff auf den Inhalt von Kunstradio ausserhalb des Web-Browsers. Mit wenigen Klicks können sie somit eine Sendung auf ihren portablen Audio-MP3-Player herunterladen und hören wann immer sie wollen.

Dieser Podcast basiert auf einem Standard, auf den sich die verschiedenen Hersteller von Podcasting-Software geeinigt haben. Der Standard ist offen und kann von jedem/r benutzt werden, somit können viele verschiedene Programme mit den Daten aus Podcasts umgehen.
