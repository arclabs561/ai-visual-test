■ 6月 4日    ( 理子 ) 
稽古に行ったり別現場に行ったり麻婆豆腐を作ったりする日々です。自転車を買いました。

初めて自転車を買ったのは大学1年生の春でした。文字通り陸の孤島にあったキャンパスまで、畑とお墓しかない道を学バスと競争しながら通学したものです。はじめての自転車通学に心も躍りました。ただ、3年生になってキャンパスが変わり、学校や駅まで徒歩3〜5分の部屋に引っ越すと、自転車は使わなくなってしまいました。あとパンクしてたし。
数年後、すっかりスクラップと化した自転車を手放して引っ越しをしたらば、今度は大体の駅やスーパーまで徒歩15〜20分かかる物件でした。皮肉なものです。

2年半ひたすら歩きましたが、ついにこの度、自転車を購入したことを報告いたします。
オリーブグリーンのかわいい自転車です。
久しぶりの自転車ライフ楽しみます。日焼け止めは忘れずに！

■ 6月 5日    ( 中川 ) 
30日、三浜リーディングの打ち合わせをリモートで。チケットが完売したので、配信もしませんかとご提案頂いたので、是非という事で、配信決定。チケットは格安の800円。永野さんと一緒に頑張ってます。よろしくお願いします。こちら

2日、この日の生配信は、26たび集まれる人集合！好きなアメを食べる会、と、素敵な発表、でした。こちら
僕は大好きなチェルシーのヨーグルト味。袋に入ってるのではなくて、スライドして開く箱に入ってるやつ。祖父に貰った記憶。
素敵なお知らせは、今年の本公演についてでした。やー楽しみ。

3日、早織さん主演の映画「辻占恋慕」こちらアフタートークへ。分からない所も沢山あって、あれどういう事なん？とか、あそこ変よねーとか、良いよねーとか、そんなアレコレが湧き出てくる、そういう話を出来る映画は、良い映画だし、そういうアフタートークは楽しいよなあと思いました。

5日、映画「ドロステのはてで僕ら」アフタートーク。満席！御来場ありがとうございました！
佐久間さんがテレビやラジオで言ってくれたおかげで、半数以上が初見の方だった。
上映中にロビーで淳太監督と待ってたら、映画館のスタッフさんが映写室から出て来て、「受けてます！笑いが起きてます！」と報告してくれた。
上映後にお客さんとお喋り。ラジオリスナーが多くて、サインしたり写真撮ってる時に、好きなラジオは何ですか？と聞くのが楽しかったです。

藤谷が日記書いてくれたなあ。そろそろ石田君とか角ちゃんも書いてくれるかなあ。

■ 6月12日    ( 中川 ) 
6日、京都へ！久しぶりにメンバーやらスタッフやらが集まっての会議。今後のヨーロッパ企画の事や、今年の本公演、そして映画第2弾の話など、ワクワクする話を沢山しました。どうぞお楽しみに。
とあるラジオドラマ収録。これも面白かった！藤谷さんと夫婦役でした。
ちょっと時間が空いたので、小林中田と食事で、トンカツ屋さんへ。近況報告など。
そして大歳と、とある街の企画の打ち合わせ。かつて僕が残した記録がそのまま使える事になり、当時の俺を誉めた。大歳は特に褒めてくれなかった。
そして、この日の生配信は、6/6(月)久々に集合記念！ヨーロッパ企画のちょっとでも数打っていこう、でした。こちら
ズーム画面ではなく、生配信。笑ったなあ。
濃い1日だった。

7日、午前中は、三浜リーディングの稽古。リーディングなのに、永野さんは台本を外そうとしている。困る。
昼から、本公演のプレ稽古。エチュードしました。面白い題材。
京都に来たのでいつも行ってる美容院へ。

8日、午前中は三浜リーディングの稽古。永野さん、昨日は覚えていた台詞が出てこなくなっていた。異世界か。
僕はまだ全く台詞が入ってない。ヤバい。
配信チケット発売中。こちら
昼から、本公演プレ稽古。この日もエチュード。再演と言いつつ、やはり演者が変わるし、出演者が増えるので、シーンも増えそう。
そして東京戻り。

9日、この日の生配信は、リーディングドラマアワード「〇〇する男ふたり」を読む男ふたり、でした。こちら
若手達がせっかく書いてくれたし、ちゃんと批評しようと思って、色々言ってたら、コメント欄に「中川さん怖い」と書かれてしまった。愛のあるやつです！

10日、とある名古屋にまつわる企画の打ち合わせ。これ上手いこと進んだら嬉しいなあ。
夜はマブダチと焼肉。大盛ご飯をお代わりした。大学生かよと言われた。

■ 6月19日    ( 中川 ) 
15日、「出番を待つふたり」で、9日の生配信でやった、左子・中田・ブレイキンの書いたリーディングドラマを、ヒロさんと藤谷さん用に書き直してもらって、やりました。オッサン2人用だったのとは全く印象が違うものになって、とても面白かった。こちら

17日、三浜リーディング「命を弄ぶ男ふたり」の上演のため、四日市へ。
名古屋駅で永野さんと、演出の中田君も合流。中田君は、こういう仕事が初めてだからなのか、緊張して、待ち合わせの1時間前から、名古屋駅に待機していたらしい。
会場の三浜文化会館は、元小学校を綺麗に改装して文化施設にしていて、校舎から電車が走ってるところが見えるし、広々していて、グラウンドもあって、素敵なところだった！
昼は、四日市公演の時も食べた、グリル四日市さんの美味しいお弁当。夜は貝バカ一代というお店で、貝の刺身、焼き、しゃぶしゃぶなど。これも最高でした。永野さんは、週ヨロの収録があるを忘れるほど堪能してました。こちら
夕方にやったゲネプロでは、永野さんがセリフを一言目から飛ばしたり、喉も飛ばしたりと、翌日の公演が心配になったので、本番当日もゲネプロをする事になった。

18日、午前中にゲネプロやって、色々チェックし、配信だけで見られる上演前挨拶動画なるものを撮影し、14時から本番。
本番ならではなトラブルがあったりもしましたが、なんとか無事終演。
そしてアフタートークをして、配信終わって、会場の方だけに向けた、さらにディープなアフタートークをして終了。
半年くらい前に、会館スタッフの宮村さんからのムチャブリでスタートした企画でしたが、やって本当に良かった。
配信は、21日22時まで購入可能。23:59まで見られますので、もし良かったら是非。1時間で終わります。破格の800円。こちら
そして実家へ。今年はツアー中で正月に実家に帰られなかったので久しぶり。嬉しい。

19日、早起きして父母とモーニング行って、実家の片付け手伝って、昼はCoCo壱でカレー食べて、昼寝して、また片付けして、兄弟も揃って、姪っ子達も来ての家族の食事会で焼肉へ。たらふく食べました。
姪っ子はもう大学三年生で髪が青かったし、一番下の子は来年中学で、初めてまともに喋った。2人ともかわいい。
そして東京へ。
