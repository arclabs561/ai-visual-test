ARESv2

ARESv2 is an upgraded version of ARES that includes new interesting features:
  • Read ASCII spectral data;
  • Cleaning of zero flux values;
  • Radial velovity correction;
  • Automatic rejt estimation for the continuum position
  • Option to use rejt dependent on wavelenght
  • EW error estimation
  • Parllelization with OpenMp for better performence
The features are described in some detail in the paper Sousa et al. (2015 A&A in press.) where the user can see some tests performed using the new features.

TMCalc

This simple code TMCalc is a C code developed as an extension to ARES. Using the line list given it uses the calibration derived for several line-rations to estimate the spectroscopic temperature for FGK dwarf stars and the use the iron lines strenght calibration to derive the metallicity [Fe/H]. The calibration for the metallicity is described in a work (Sousa et al. 2012, A&A, 544, 122) .

ARES

ARES is a C code developed for the measurement of Equivalent Width of absortion lines in stellar spectra.
The code reads a 1D FITS spectra and fits the requested lines in order to calculate the Equivalent width.
The Code is described in the paper by Sousa et al. 2007, A&A, 469, 783, where the user can see the results of tests of this code for several types of spectra.

LineSearcher

The LineSearcher code, is a derivation from the ARES code. You can use this code to search all the absortion lines in a given wavelength interval. This code returns the center wavelength and estimated depth for each line found in the interval.

Line-Ratio Calibration Code

This simple code Teff_LR is a C code developed as an extension to ARES. Using the line list given it uses the calibration derived for several line-rations to estimate the spectroscopic temperature for FGK dwarf stars. The line-ratio calibration are described in Sousa et al. 2010, A&A, 512, 13
